[官方设备仓库说明](https://unixnu.com/zh/porting/device-repository)和[已有仓库迁移指南](https://unixnu.com/zh/porting/migration)定义了新版设备描述与记录流程。本仓库仍有历史布局，不能声称完成新版规范迁移：

| 项目 | 实际状态 / 后续要求 |
| --- | --- |
| `board.toml` | 仍为旧格式与早期 standalone 入口；需将真实 prelink/OS profile/组件输入迁入新格式，并从全新目录构建、上机复验 |
| `porting.toml` / Porting record CI | 尚未建立完整结构化记录与已通过的官方工作流；本文和 JSON 收据不能冒充该检查 |
| 板级 DTS / SoC 分层 | 当前仍有本机 ADT 生成与有序补丁路线；共享 SoC、设备 DTS 和组件边界迁移需单独验证 |
| `patches/xnu/series` | 当前回放器实际使用 `patches/xnu-8796-kebab/` 的文件名排序；不能改路径后不更新并验证生产构建入口 |
